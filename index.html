📻 Non-stop radio stations

The car radio only plays direct audio streams (.mp3 / .pls / .m3u), not YouTube or Spotify links. Pick a station, hit Copy link, paste it into the radio and press Enter. It keeps playing, no more links needed.

Connect Spotify (optional)

Lets you find stations that match what you are playing, and get YouTube links for radios that take them. Setup takes about 3 minutes:

  1. Go to the Spotify Developer Dashboard and click Create app.
  2. Name it anything (e.g. "GMod Radio"). Tick Web API.
  3. Under Redirect URIs, paste this exact address and click Add:
  4. Save, then copy the app's Client ID and paste it here:

Optional but recommended: add a free YouTube API key in ⚙️ Settings so the site can find the YouTube link automatically. Without it you get a one-click YouTube search instead.
